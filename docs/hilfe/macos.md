# macOS-Bildschirmfreigabe

Die Bildschirmfreigabe von macOS ist VNC mit Apple-Anmeldung. Man meldet sich mit einem
**macOS-Benutzerkonto** an.

## Einrichten

**Systemeinstellungen › Allgemein › Teilen › Bildschirmfreigabe** einschalten.

Über das Info-Symbol (ⓘ) daneben festlegen, wer zugreifen darf: alle Benutzer oder nur
bestimmte.

## In Sesam

- Desktop (VNC) aktiv, Port 5900.
- Benutzer: der Kurzname des macOS-Kontos.
- Passwort des Benutzers: das Passwort dieses Kontos.
- Das Feld **VNC-Passwort** bleibt leer.
