## Description (4000)

```
Sesam Remote brings the desktop, shell and files of your computers to the iPad, in one app with one library for all connections.

REMOTE DESKTOP
• RDP for Windows (Pro/Enterprise), Windows Server and Linux (GNOME Remote Desktop, xrdp), with sound and shared text clipboard
• VNC for Mac Screen Sharing, Raspberry Pi and Linux
• Touch control as trackpad or direct, zoom, on-screen keyboard with an extra row for Ctrl, Alt, Esc, Tab, arrows and function keys, "Send keys" for key combinations
• H.264 decoded by the iPad's hardware

SHELL (SSH)
• Terminal with tabs, search, snippets and many color schemes, including Sesam's own light and dark themes
• Sign in with password or SSH key; Sesam can generate keys for you
• Persistent shell with tmux: the session keeps running on the server even when iPadOS drops the connection in the background
• Port forwarding: reach services in the server's network through an SSH tunnel

FILES (SFTP, FTP)
• Two panes: the iPad on the left (folders from the Files app, iCloud Drive, USB drives, network shares), the server on the right
• Upload, download, rename, delete with a trash folder on the server and undo
• Drag files from the Files app straight onto a shell or remote desktop (Split View, Slide Over)

LIBRARY
• Cards or list, colored groups, search
• Online status and Wake-on-LAN
• "First aid" checks name resolution, reachability, port, service and sign-in and shows what is wrong
• "Enable desktop" sets up screen sharing on Ubuntu and Raspberry Pi over SSH, step by step and with confirmation
• "Open connection" shortcut for the Shortcuts app, Spotlight and Siri

SECURITY AND PRIVACY
• Passwords and keys are stored in the iPad keychain; revealing them requires Face ID, Touch ID or the passcode
• Server and certificate fingerprints are verified and remembered
• No account, no relay server, no ads, no tracking: Sesam sends no data to us
• Encrypted backup of library and credentials as a file

GOOD TO KNOW
• Sesam is a client. The computers you connect to need RDP, VNC or SSH turned on.
• iPadOS does not keep connections open in the background. When you switch apps, Sesam reconnects on return; a persistent shell (tmux) keeps running on the server.
• System shortcuts such as ⌘Tab stay with the iPad; use the extra key row and "Send keys" instead.
• For computers on your own network, iPadOS asks once for local network access.

Please note: the app's interface is currently in German only.

Sesam Remote is open source (Mozilla Public License 2.0) and is also available for Mac, Windows and Linux at sesam-remote.app.
```
