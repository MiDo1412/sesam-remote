# sesam-remote.app

Statische Website, ohne Build. Den Inhalt dieses Ordners (ohne diese Datei) auf den Webspace laden.

Vor dem Hochladen:

- **Domain:** überall steht `https://sesam-remote.app/` (index.html, robots.txt, sitemap.xml, llms.txt,
  Unterseiten). Bei anderer Domain alles ersetzen.
- **E-Mail:** `support@sesam-remote.app` (Support und Datenschutz) muss eingerichtet sein.
- **Downloads:** die Knöpfe laden direkt die Dateien des neuesten GitHub-Releases
  (`releases/latest/download/…`), hier muss nichts abgelegt werden.
- **iPhone und iPad:** im App Store unter https://apps.apple.com/ch/app/sesam-remote/id6834800137 (iPad seit 15.11.2026, iPhone seit 20.11.2026,
  vorerst nur Schweiz), mit Apples Abzeichen `img/app-store-badge-de-{schwarz,weiss}.svg`
  (von toolbox.marketingtools.apple.com, unverändert; schwarz im hellen, weiss im dunklen Modus).
- **App Store Connect:** Support-URL `https://sesam-remote.app/support.html`, Datenschutz-URL `https://sesam-remote.app/datenschutz.html`, App-Datenschutz «Keine Daten erfasst».

`.htaccess` gilt für Apache (Typen, Komprimierung, Cache, CSP). Screenshots neu erzeugen: `../website-tools/README.md`.

Kein Impressum (Entscheid Mike, 11.11.2026): kostenlose App ohne Verkauf, Anbieter mit Name und E-Mail in der Datenschutzerklärung. Wird Sesam verkauft, braucht es eine Adresse (UWG Art. 3 Abs. 1 lit. s).
